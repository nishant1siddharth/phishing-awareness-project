Please read this information before starting the simulation.

What This Simulation Involves

  • This is an educational simulation of a phishing email and a fake login page.
  • It is intended only for authorized participants as part of a cybersecurity awareness exercise.
  • You should never enter a real password on the simulated login page.
  • Only anonymous interaction events are measured — no personal information is collected.
  • After the simulation, you will receive a full explanation of the techniques used.
ℹ️
Nothing you type into the simulated login form is ever transmitted or stored.

The form only records the harmless fact that a login attempt occurred.
