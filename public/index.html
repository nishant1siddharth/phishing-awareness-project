Project Overview

This application is an authorized, controlled, educational simulation built to demonstrate how phishing and social-engineering attacks work in practice, how users tend to respond to them, and how awareness training measurably changes that response. All content — the fictional organization, the simulated email, and the simulated login page — is entirely fabricated for demonstration purposes and does not impersonate any real company or service.

Objectives

🎯

Demonstrate the Mechanism

Show concretely how a phishing message and a fake login page are constructed and why they work.

👁️

Observe Interaction

Track anonymous, harmless interaction events to see how participants respond to a simulated lure.

🚩

Highlight Warning Signs

Teach participants the concrete signals that distinguish a phishing attempt from a legitimate message.

📊

Measure Awareness

Aggregate anonymous results into a dashboard showing click rates, report rates, and login-attempt rates.

🛡️

Present Preventive Measures

Provide practical, actionable guidance participants can apply to reduce real-world phishing risk.

How the Simulation Works

  1. Read the consent and information page before beginning.
  2. View a simulated phishing email from a fictional company.
  3. Choose to report it as phishing, or click the embedded link.
  4. If clicked, a simulated login page appears — no real password is ever transmitted.
  5. Review the awareness guide explaining the warning signs you encountered.
  6. See anonymous, aggregate results on the results dashboard.
